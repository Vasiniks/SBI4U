# SBI4U study guides

Static study site for Grade 12 University Biology, published with GitHub Pages from `docs/`.

- `docs/biochem/` — Unit 1 Biochemistry.
- `docs/metabolism/` — Unit 2 Metabolic Processes (cellular respiration and photosynthesis).
- `docs/genetics/` — Unit 3 Molecular Genetics (history, DNA structure, replication, transcription, translation, mutations, operons), with step-through diagrams and sequence tools.
- `docs/test/` — mixed test across all units.
- Each unit has lessons, class Q&A, practice quiz, application questions, beyond-the-slides topics, glossary and a cram sheet. Content lives in `docs/<unit>/data/*.js`; the shared app is `docs/assets/app.js` with `docs/assets/style.css`.

Open `docs/index.html` in a browser to use it locally.
