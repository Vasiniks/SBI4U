# SBI4U study guides

Static study site for Grade 12 University Biology, published with GitHub Pages from `docs/`.

- `docs/metabolism/` — Unit 2 Metabolic Processes: lessons, class Q&A, practice quiz, application questions, beyond-the-slides topics, glossary.
- Content lives in `docs/metabolism/data/*.js`; the app is `docs/metabolism/js/app.js`.

Open `docs/index.html` in a browser to use it locally.
